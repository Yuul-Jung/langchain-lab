① 로컬 실행 환경 준비

GitHub Pages는 공개 학습 화면입니다. 여기서 PC 프로그램을 직접 실행하지는 않습니다. Ubuntu 터미널에서 아래 명령을 실행한 후 로컬 채팅으로 이동하세요. 이미 설치한 프로그램은 다시 설치하지 않습니다.

1첫 실행 / 코드 업데이트프로젝트 소스·라이브러리 확인, 테스트, FastAPI 서비스 업데이트
2매일 로컬 서버 시작FastAPI와 LM Studio 상태 확인, 필요 시 시작. Elasticsearch는 상태만 확인
3로컬 서비스 접속127.0.0.1:8000에서 채팅과 PDF 관리 실행
최초 설정 또는 소스 업데이트 (필요할 때만)
cd ~/langchain_web && bash scripts/update-local.sh
평소 실행 (매번 이 명령 하나)
cd ~/langchain_web && bash scripts/start-local.sh

2026년 11월 이후 추가된 실행 스크립트가 아직 PC에 없는 경우, 최초 한 번 아래 명령으로 가져옵니다.

cd ~/langchain_web && git pull --ff-only origin main

로컬 주소가 열리지 않으면 먼저 실행 명령의 진단 결과를 확인하세요. 외부 GitHub Pages에서는 운영체제 보안상 로컬 서비스를 직접 시작하거나 정상 작동 여부를 확정할 수 없습니다.
