# 검증 세트 명세 2 — 제약 판정과 회로 수준 검사 (초안, 71 작성, jung-29 검토 전)

상태 표시는 모두 **위임(두 Claude 세션)** 이며 사람의 확인이 아니다. 생성된 사례 파일은 이 PC에만 두고(`data/verification/`), 이 명세와 생성 규칙(씨앗 포함)만 커밋한다.

## 0. 왜 새 방식인가
지난 판정 10번에서 규칙을 만든 쪽이 쓴 연습 세트의 개선이 봉인 세트에서는 훨씬 작았다(+10 대 +3). 그래서 ① 경우의 수를 먼저 표로 정하고 ② 연습·봉인을 경우의 *묶음*으로 나누며 ③ 정답을 엔진과 **독립**으로 만든다.

## 1. 대상
`eda_harness/edaharness/constraints.py` 의 `resolve` · `check_operating_point` (부품 단독 판정). 이후 단계(2단계)에서 회로 블록과 넷(여러 부품이 같은 전원을 쓰는 경우)으로 넓힌다.

## 2. 경우의 수 (1단계: 부품 단독)
판정 입력 = 필드 5개의 증거 상태 + 동작점(전원 전압, 주변 온도 범위).
| 축 | 수준 |
|---|---|
| 필드 | supply_min_v · supply_max_v · abs_max_supply_v · temp_min_c · temp_max_c (5개) |
| 필드의 증거 상태(8) | 없음 · 데이터시트만 · 유통사만 · 라이브러리만 · 데이터시트=유통사(일치) · 데이터시트≠유통사 · 유통사≠유통사(같은 단계 충돌) · 위임 확인(데이터시트+tier) |
| 전원 위치(7) | 권장 최소 미만 · 권장 최소 · 권장 안 · 권장 최대 · 권장 최대와 절대 최대 사이 · 절대 최대 · 절대 최대 초과 |
| 온도 위치(5) | 범위 미만 · 최저 · 안 · 최고 · 초과 |
| 한계 값 모양(프로필 12) | 여러 전압대(1.8·3.3·5·12·24V …)·온도 등급(상업·산업·차량·군용)·좁은 범위·넓은 범위 |
전수 조합은 8⁵×7×5×12 ≈ 1,400만이라 쓰지 않는다.

## 3. 사례 뽑기
- **쌍별 덮기(pairwise)**: 필드 상태 5개와 전원 위치·온도 위치 사이의 모든 수준 쌍이 적어도 한 번 나오게 하는 작은 집합을 결정적으로 만든다(탐욕 알고리즘, 고정 씨앗).
- **위험 3자 조합을 따로 채운다**(각 칸 30개 이상, 프로필·값을 바꿔서):
  1. 절대 최대 없음(또는 유통사만) × 전원 위치 '절대 최대 초과' → 정답은 위반이 아니라 **판정 불가/경고**, 통과가 되면 안 됨
  2. 전원 필드의 같은 단계 충돌 × 모든 전원 위치 → 항상 충돌(판정 불가)
  3. 위임 확인 값 × 권장 범위 밖 → 위반 + 위임 경고
  4. 데이터시트≠유통사 × 경계 위치 → 데이터시트 값이 이김
  5. 온도 한쪽만 있음 × 반대쪽 초과 → 판정 불가
- **칸 규모 규칙**: 한 칸이 30개 미만이면 그 칸은 설명용으로만 보고하고 기준에 쓰지 않는다(한 사례가 기준을 3% 넘게 움직이지 않게).

## 4. 정답(오라클) — 엔진과 독립
1. **표 오라클**: `verification/oracle_constraints.py`. 엔진을 import 하지 않는다. 규칙을 산술로 따로 적는다(증거 단계 순서, 같은 단계 값 불일치 = 충돌, 없음 = 판정 불가, 경계 포함 비교). 입력은 사례의 구체적 숫자뿐.
2. **성질 오라클(정답 값 없이도 검사)**:
   - 전원을 올려도 위반이 통과로 바뀌지 않는다(단조성, 한계 전후).
   - 같은 증거의 순서를 바꿔도 판정이 같다.
   - 낮은 단계 값을 더해도 높은 단계 판정이 바뀌지 않는다.
   - 값이 빠지면 통과가 되지 않는다(없음 → 판정 불가 또는 위반, 절대 통과 아님).
   - 한계 값을 안전 방향으로 좁히면 통과가 위반으로만 바뀐다.
3. 표 오라클과 엔진이 어긋나면 **어느 쪽이 틀렸는지 규칙 문장으로 판정**하고, 엔진이 틀리면 엔진을, 오라클이 틀리면 오라클을 고친 뒤 기록한다(결과에 맞춰 규칙을 바꾸지 않는다).

## 5. 연습/봉인 분리 (과적합 방지)
- 사례 번호의 해시로 나누고(나중에 옮길 수 없음), 한계 값 프로필 12개를 **연습 8 / 봉인 4**로 나눈다. 봉인 프로필의 값 모양은 연습에 나오지 않는다.
- 봉인 세트는 엔진 코드를 바꾸기 전에 만들어 해시를 기록하고, **한 번만** 본 뒤 은퇴한다.
- 코드 고정 뒤에는 연습 때 없던 새 씨앗으로 다시 만든다.
