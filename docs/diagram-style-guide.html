STANDARD UI SYSTEM · VERSION 1.0

학습용 HTML 블록다이어그램
표준 템플릿 & 구조도 세트

로컬 AI/RAG 구축 교재의 디자인을 표준화한 재사용 가능한 HTML/CSS 기반 구조도 모음. Mermaid나 SVG 없이 의미 있는 HTML 박스를 사용하며, 브라우저 확대·인쇄·화면 크기에 대응한다.

둥근 사각형옅은 회색·파랑제목 + 역할 설명최소 화살표2열 병렬 구조
디자인 규칙① 시스템② RAG③ 벡터 검색④ 자동 시작⑤ 오류 진단⑥ 문서 등록재사용 방법

08. 다른 HTML 교재에 재사용하는 방법

최소 HTML 블록 예시

<div class="diagram">
  <div class="node">
    <strong>입력 모듈</strong>
    <p>센서 데이터 수신</p>
  </div>
  <div class="arrow">↓</div>
  <div class="node primary">
    <strong>controller</strong>
    <p>제어 상태 처리</p>
  </div>
</div>

디자인의 핵심은 .diagram · .node · .node.primary · .arrow · .grid2입니다. 다른 HTML 자료에서도 공통 CSS만 복사해 재사용할 수 있습니다.

표현 기준: 화살표는 흐름의 방향을 뜻한다. 운영환경은 실행 기반이므로 데이터 흐름 박스처럼 오해되지 않도록 설명을 병기한다. FPGA/RTL 자료의 구조도는 실제 모듈명과 신호명을 우선 사용한다.
